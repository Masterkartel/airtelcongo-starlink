    Questions fréquentes
    Tout ce qu'il faut savoir
    Comment se passe le paiement ?
    Le paiement se fait via Airtel Money — vous recevez une notification sur votre téléphone, entrez votre code PIN à 4 chiffres, et la transaction est validée en quelques secondes. Vous recevez ensuite un code OTP par SMS.
    Combien de temps pour activer mon forfait ?
    Environ 30 secondes après confirmation du paiement. Vous recevez un SMS avec les instructions, et votre connexion est immédiatement opérationnelle.
    Puis-je utiliser mon forfait partout en RDC ?
    Oui. Le réseau Airtel couvre les 26 provinces — y compris les zones rurales, les sites miniers et les chantiers isolés.
    Que se passe-t-il si je change d'avis ?
    Vous pouvez annuler à tout moment avant la confirmation finale du paiement. Une fois activé, le forfait reste valable pendant la durée choisie.
    Puis-je recharger plusieurs fois ?
    Oui, vous pouvez recharger votre ligne autant de fois que nécessaire. Les forfaits achetés s'ajoutent à votre solde actuel.
